## About The Project

This is the personal portfolio website of Dinithi Dewmini, an Information Technology undergraduate at the University of Moratuwa. 

It is crafted with a focus on modern web aesthetics, smooth animations, glassmorphism, and responsive design to present projects, hackathon achievements, certifications, and technical proficiencies in an engaging format.

---

## Key Features

- **Iridescent & Dynamic Visuals:** Shader effects powered by WebGL/OGL and smooth micro-interactions.
- **Modern Dark UI/UX:** Designed with Tailwind CSS featuring fluid gradients and glassmorphism.
- **Framer Motion Animations:** Smooth scroll reveals, hovering states, and responsive transitions.
- **Fully Responsive:** Seamlessly adapts across mobile, tablet, and desktop screens.
- **Project Showcase:** Detailed cards with live links, GitHub repositories, and tech tags.
- **Certifications & Education:** Interactive milestones, hackathon awards, and verified credentials.
- **Interactive Contact Form:** Direct messaging and social links to connect easily.

---

## Tech Stack

### Frontend & Styling
- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **WebGL / Graphics:** OGL
- **Icons:** Lucide React
