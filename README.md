## About The Project

This is the personal portfolio website of **Dinithi Dananjana**, an Information Technology undergraduate at the **University of Moratuwa**.

It is crafted with a focus on modern web aesthetics, smooth animations, glassmorphism, and responsive design to present projects, hackathon achievements, certifications, and technical proficiencies in an engaging format.

---

## Key Features

- **Modern Dark UI/UX** -- Designed with Tailwind CSS featuring fluid gradients and glassmorphism
- **Framer Motion Animations** -- Smooth scroll reveals, hovering states, and responsive transitions
- **Fully Responsive** -- Seamlessly adapts across mobile, tablet, and desktop screens
- **Project Showcase** -- Detailed cards with live links, GitHub repositories, and tech tags
- **Certifications and Education** -- Interactive milestones, hackathon awards, and verified credentials
- **Interactive Contact Form** -- Direct messaging and social links to connect easily

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion 12
- **Icons:** Lucide React

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18.x or higher recommended).

### Installation and Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dinithi1625403/Portfolio.git
   cd Portfolio/frontend/my-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view the application.

5. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
