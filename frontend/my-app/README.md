# Dinithi Dananjana - Developer Portfolio (Frontend)

A modern, interactive personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion.

---

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion 12
- **Icons:** Lucide React
